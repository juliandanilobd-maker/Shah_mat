# Instrucciones para visualizar archivos .puml
Para explorar los archivos .puml, en VS Code sin necesidad de instalar programas, sigue los siguientes pasos:

1. Instala la extension PlantUML en VS Code.
2. Abre la paleta de comandos (Ctrl + Shift + P).
3. Selecciona "Preferences: Open User Settings (UI)".
4. Dirigete a la opción: plantuml.render.
5. En el menú desplegable, cambia de Local a PlantUML Server.
6. Justo debajo se encuentra la opción plantuml.server.
7. Asegurate que diga o escribe: "https://www.plantuml.com/plantuml"
8. Y listo, dirigete al documento y coloca el comando Alt + D y visualiza el documento.
